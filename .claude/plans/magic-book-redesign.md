# 魔法书六皮肤全面美化方案

## 目标
六本魔法书各自独立、炫酷美观、细节耐看。覆盖全部 6 个面(正面/后封/书脊/右页摞/顶/底)。

## 现状问题
1. 六本书结构同一套模板,只换色 + 四角小纹样区分。
2. 烫金边/角饰/法阵全是**扁平纯色描边**,没有金属反光质感。
3. 中心法阵六本都是「双圆环 + 八刻线 + 小圆点」一套。
4. 后封六本**完全相同**。
5. 标题/印章布局所有书一致。

## 架构策略(不动 3D 管线)
`buildFaceBitmaps` 仍调用 `drawMiniCover / drawBackCover / drawSpineVertical / drawPageEdgeVertical / drawPageEdgeHorizontal`。
改为在这些入口按 `skin.id.raw` 分派到**每本书专属**的绘制函数。

### 新增共享「材质级」工具(全书受益,统一质感)
放在 BookCoverPreview.kt 顶部:
- `drawMetallicStroke(...)` — 金属描边:主色 + 高光线 + 暗边,替代扁平纯色描边。
- `drawMetallicFill(rect, foilPair)` — 金属面填充(双向渐变模拟反光)。
- `drawGemstone(center, r, color)` — 刻面宝石:底色 + 高光点 + 暗角 + 环形描边。
- `drawEmbossText(...)` — 升级版三层凸压(已有,抽成复用 + 加金属渐变描边)。
- `radialVignette(...)` / `softGlow(...)` — 柔光晕(非纯白,皮肤色,杜绝白光晕复发)。

> 安全:所有 radius/size/strokeWidth 一律 `coerceAtLeast(1f)` 防 NaN 崩溃;侧面绝不画纯 `Color.White` 大面积高光(防深背景反白)。

## 六本书专属设计

### 1. 蘅芜旧卷 · 暗夜墨金(文人藏书)
- **正面**:中央如意云纹徽记环抱一枚朱砂方印,墨金双框 + 四角卷云,竖向典雅书名。克制、书卷气。
- **后封**:藏书票式 —— 中央如意云纹团花 + 古文藏书铭 + 边框回纹。

### 2. 霁月长明 · 紫电夜幕(月相天盘)
- **正面**:中央满月银盘,四周环绕月相小盘(朔→望),银色星座连线,雷击焦痕(已有 FX)。
- **后封**:银色星图盘 + 月相刻度环。

### 3. 晴川早春 · 夜樱微光(樱花和风)
- **正面**:一枝樱花斜贯封面,玫瑰金细框,柔和留白,**不要重法阵**。书名手札感。最轻盈雅致。
- **后封**:散落樱花 + 玫瑰金细框 + 和风短歌题字。

### 4. 赤焰天书 · 焚天熔炉(火凤天书)
- **正面**:中央火凤/烈焰法阵,炽金日芒放射,灼烧焦痕(已有 FX)。强势炽烈。
- **后封**:火焰纹章 + 熔金封印。

### 5. 青鸾翠竹 · 翠林夜雾(翠竹青鸾)
- **正面**:翠竹枝 + 银色青鸾(凤鸟)徽记,玉色面板,银描边。清雅。
- **后封**:翠竹丛 + 青鸾环徽。

### 6. 星河长卷 · 深海星渊(星轨罗盘)
- **正面**:中央星盘/星象罗盘,星座连线,银色刻度环,深蓝。航海星图感。
- **后封**:大星图 + 罗盘方位环。

## 书脊 / 页摞 / 顶底(6 面统一升级 + 皮肤点缀)
- 书脊:金属渐变 ridge + 每本专属顶/底徽记(对应主题:云纹/月/樱/焰/竹/星),竖排书名金属描边。
- 右页摞:金属切口 + 皮肤色丝带书签 + 标签;质感升级,保留现有结构。
- 顶/底切口:质感微调,跟随皮肤色。

## 实施顺序(每步编译验证)
1. 共享材质工具函数(metallic / gemstone / glow / emboss)。
2. 正面 6 本分派 + 6 个专属正面函数。
3. 后封 6 本分派 + 6 个专属后封函数。
4. 书脊按主题分派顶/底徽记;页摞 + 顶底质感升级。
5. `:app:compileDebugKotlin` → `:app:assembleDebug` → 安装真机。

## 验证 / 约束
- 每完成一块就 `compileDebugKotlin` 编译验证。
- 全部完成后 assembleDebug + adb install,请用户逐皮肤目检。
- 不重新引入书后圆盘光晕(上一任务已删除);侧面不反白。
- 字符串字面量(书名/题字)直接内嵌,不新增 strings.xml(保持现有做法一致)。
