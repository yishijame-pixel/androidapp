# 顶部抽屉（窗 / 星海）—— 用户自定义 & 玩法方案池

> 三轮头脑风暴的方案集合，按"工作量 × 体验深度"分组。
> 状态：**待定**（用户正在筛选中）。

---

## 第一轮：用户自定义机制（外观层）

### A. 图层开关 · 轻量
每个 skin 提供齿轮入口，弹出图层勾选面板：
- 云 / 星 / 雾 / 飞鸟 / 月相 / 光线 / 印章 / 诗句 / 签到按钮 / 北斗 / 流星 …
- 用户勾选自己想要的元素，立刻生效。

**优点**：实现简单（每个图层一个 Boolean 开关），改动最小。
**适合**：让用户做"减法"得到自己的极简版本。

---

### B. 主调调色 · 中量
每个 skin 提供色盘选择器：
- 背景主色、点缀色、文字色独立可调
- 预设色卡 3-5 套：青青子衿 / 黑金 / 枫红 / 月白 / 极昼 …
- 一键应用，可保存为"我的方案 A/B/C"

**优点**：视觉个性化强但不需要重做布局。
**适合**：颜色敏感型用户。

---

### C. 画布拼贴 · 重量
全新"创作"页：空白宣纸 / 夜空作画布。
- 素材库：远山、云、鸟、月相、诗句、印章、星点、灯笼 …
- 用户拖拽上去，可移位、缩放、改色、改透明度
- 完成后保存为自己的 skin

**优点**：体验最强，每个用户的窗都不一样。
**缺点**：工作量大（需要素材库 + 编辑器 + 保存机制）。

---

### D. 文案定制 · 轻量
只让用户改"说什么"：
- 顶部问候语（默认"清晨"→ 自定义"早安，{你的昵称}"）
- 中央诗句 / 时辰诗（可关闭系统诗，写自己的）
- 印章里的字（默认十字镂空 → 改成"心"、"安"、用户姓氏）
- 签到文案（"早安签到" → "今天也要加油"）

**优点**：最小改动 + 个人化感强。
**适合**：希望文字"是自己的话"的用户。

---

## 第二轮：有"灵魂"的方向（体验层）

### E. 情绪镜像 · 隐式映射
窗不再随时间变，而是随 **最近 7 天 mood 平均值** 变：
- 开心渐多 → 窗变温暖 / 阳光穿透 / 飞鸟成群
- 低落 → 转阴雨 / 雾重 / 飞鸟稀少
- 平稳 → 黄昏柔光

**亮点**：用户什么都不用设，"窗读你的心"。和 mood app 的核心数据深度耦合 —— 别家做不出来。

---

### F. 节气 + 天气联动 · 真实
接入天气 API + 节气历：
- 现实下雨 → 窗外真下雨；起雾 → 起雾；下雪 → 飘雪
- 节气特效：清明叠雨、大雪堆雪、中秋超大月、冬至一阳初生、立春破冰
- 用户开关"是否启用真实天气"

**亮点**：让"窗"成为现实窗户的延伸 —— 抬头看窗内 = 抬头看窗外。

---

### G. 连你的星座 · 手绘星图
在星海里：
- 长按某颗星进入"连线模式"
- 手指拖连数颗 mood 星，连成自己的星座
- 命名：「初恋三周座」「面试连过座」「周五下班酒座」…
- 点击星座 → 回顾那段时期的所有心情记录
- 可保存、备份、分享星图

**亮点**：把 mood 数据转成"个人神话"。全世界只属于你的魔幻星图。

---

### H. 愿望漂字 + 守候仪式
- 用户手写一句心愿 / 座右铭 → 极淡手写体在天空 / 星海中漂动，随云流动
- 设置"守候日"：发工资日、生日、纪念日 …
- 当天打开 → 仪式感动画（烟火 / 花瓣 / 灯笼 / 钟声）

**亮点**：把 app 变成有"重要日子"的伙伴。

---

## 第三轮：长期陪伴 & 仪式感（情感层）

### I. 生命之树 · 长期纯度
窗外有一棵树：
- 每条 mood = 一片叶子，颜色 = 心情等级
- 一年下来叶茂 / 稀疏，一目了然
- 春天发芽、夏天浓绿、秋天金黄落叶（旧记录变叶飘落但保留）、冬天露枝
- 多年后 → 一棵长着你"一生心情"的树

**亮点**：长期价值最强，是用户的"年轮"。

---

### J. 一年前的今天 · 回响
打开星海时：
- 一年前同一天记下的星 → 突然闪亮、2s 后浮出当时写的话（手写体）
- 重要节点（3 个月 / 半年 / 一年前）加强动画
- 轻轻提醒"你走过的路"

**亮点**：时间感动效，让旧数据有"回响"价值。

---

### K. 影子时钟 · 可拖动的太阳
在"窗"中：
- 太阳 / 月亮可被手指拖动 —— 拖到天顶 = 正午、拖到地平线 = 黄昏
- 整个窗的色调 / 云 / 鸟 / 诗句随之 **实时**变化
- 手一松 → 回到当前现实时间

**亮点**：纯粹好玩的交互。让用户能"穿越看到任意时辰"。

---

### L. 漂信瓶 · 给未来自己
- 写一句话装进玻璃瓶
- 选多久后漂回：1 周 / 1 个月 / 1 年
- 瓶子在窗外天空 / 星海缓慢漂动（有视觉持续陪伴感）
- 到期推送 → "一个月前的你对你说了句话"

**亮点**：给未来自己的微小仪式，结合 app 长期使用属性。

## 备选池（散思）

未单独提问但值得记录：

- **共时态共鸣**：全球此刻打开 app 的用户，他们当地时辰以小亮点闪烁在你的星海里。"此刻此地，有 273 人也在看着自己的星海"。孤独感 → 联结感。
- **抚触互动**：长按窗外的云 → 摸散；长按星 → 变成花。让用户用手指给画面留痕。
- **二十四时辰诗收集**：每两小时打开窗能"采撷"那个时辰的诗，集齐 12 时辰解锁"昼夜全集"。游戏化。
- **本命星**：用户选一颗"本命星"，永远在固定位置最亮，是用户自己。其他星 = 旁人 / 记忆。本命星随连续打卡天数变大。
- **季节迁徙生物**：春天燕子归、夏天蜻蜓低飞、秋天大雁南飞、冬天枯枝寒鸦。生物随真实季节变。
- **梦境随机**：每天早晨 6 点，从过去 30 天 mood 中抽 3 条组成一段"昨夜的梦"。"昨夜你梦见了：周三的烦躁 + 上周日的雀跃 + 三周前的疲惫……"。
- **声音雨**：每条 mood 化作一滴雨落在窗外水面，激起涟漪。涟漪大小 = 心情强度。可加雨声。
- **一日一物**：每天可在窗里放一个"今日之物"（叶子 / 石头 / 茶 / 书图标库），长期累积成"物件博物馆"。
- **对话窗**：用户写一句话，窗以诗或问候回应（本地规则匹配，无需 AI）。
