# 屏幕适配指南（企业级多机型自适应）

> 工具包目录：`com.example.funlife.ui.utils.*`
> 全局已在 `MainActivity` 注入 `LocalScreenAdapter`，所有 Composable 直接可用。

## 文件结构

```
ui/utils/
├── ScreenAdapter.kt       # 核心：尺寸/方向/字号 感知，提供 rdp/rsp 扩展
├── DesignTokens.kt        # 设计令牌：Spacing/Radius/TextSize/IconSize
├── AdaptiveComponents.kt  # 组件库：AdaptiveScaleBox / ResponsiveDialogBox / BottomTabSafeColumn
└── AdaptivePreviews.kt    # 多机型预览注解：@AdaptivePreviews / @PhonePreviews / @FontScalePreviews
```

## 一、四个核心 API

### 1. 响应式 dp / sp（最常用，**单点替换式**）

```kotlin
import com.example.funlife.ui.utils.rdp
import com.example.funlife.ui.utils.rsp

// 任意 Composable 中：
Box(modifier = Modifier.size(100.rdp))   // 100dp 自动按屏宽缩放（0.85x ~ 1.25x）
Text("Hi", fontSize = 16.rsp)             // 16sp 同理
```

适用：图片、按钮、icon、卡片宽高、文字字号。

### 2. `rememberScreenAdapter()`（需多次取值时）

```kotlin
val sa = rememberScreenAdapter()
sa.widthDp      // 屏幕宽 dp
sa.isShortScreen // 是否短屏 (<640dp 高)
sa.isLargeScreen // 是否大屏 (≥600dp 宽，平板/折叠)
sa.dp(20)       // = 20.rdp
sa.sp(14)       // = 14.rsp
```

### 3. `bottomTabContentPadding()`（Tab 屏滚动列表必用）

```kotlin
LazyColumn(
    contentPadding = bottomTabContentPadding(top = 8.dp, horizontal = 16.dp)
) { ... }
```

底部留 120dp（90dp 导航 + 30dp 呼吸）— 避免内容被底部导航栏遮住。

### 4. 整页/动画自适应缩放（**一行代码全局生效**）

```kotlin
import com.example.funlife.ui.utils.AdaptiveScaleBox

AdaptiveScaleBox(modifier = Modifier.fillMaxSize()) {
    // 整组内容自动按屏幕缩放，250.dp / 180.sp 等硬编码完全不用动
    Column { ... }
}
```

**推荐用法**：全屏激活动画、庆祝弹层、大尺寸 Splash。已应用于 `VipActivationAnimation`。

## 一·五、企业级组件库（推荐用法）

### 5. `ResponsiveDialogBox`（自适应 Dialog）

```kotlin
Dialog(onDismissRequest = { ... }) {
    ResponsiveDialogBox {  // 自动限宽 92%/最多 480dp，限高 85%
        Card(...) { ... }
    }
}
```

### 6. `BottomTabSafeColumn`（Tab 屏垂直滚动容器）

```kotlin
BottomTabSafeColumn(rememberScrollState()) {
    // 内容...
    // 自动追加 90+30 = 120dp 底部留白，无需手写 Spacer
}
```

### 7. 设计令牌（替代硬编码 dp/sp）

```kotlin
import com.example.funlife.ui.utils.Spacing
import com.example.funlife.ui.utils.Radius
import com.example.funlife.ui.utils.TextSize
import com.example.funlife.ui.utils.IconSize

Spacer(Modifier.height(Spacing.md))            // 16dp 自适应
Card(shape = RoundedCornerShape(Radius.lg))    // 16dp 自适应圆角
Text("Hi", fontSize = TextSize.title)          // 18sp 保守缩放
Icon(..., modifier = Modifier.size(IconSize.lg))  // 24dp 自适应图标
```

可用值（统一 4dp 步进）：
- **Spacing**：`xxs(2) xs(4) sm(8) md(16) lg(24) xl(32) xxl(48)`
- **Radius**：`xs(4) sm(8) md(12) lg(16) xl(20) xxl(24) pill(999)`
- **TextSize**：`tiny(10) xs(11) sm(12) body(14) md(16) title(18) headline(20) display(24) hero(32)`
- **IconSize**：`xs(12) sm(16) md(20) lg(24) xl(32) xxl(48)`

### 8. 多机型预览注解

```kotlin
import com.example.funlife.ui.utils.AdaptivePreviews

@AdaptivePreviews   // 一次预览 4 种机型
@Composable
fun MyScreenPreview() {
    FunLifeTheme { MyScreen() }
}
```

可用：`@AdaptivePreviews` `@PhonePreviews` `@OrientationPreviews` `@FontScalePreviews` `@ThemePreviews`

## 二、什么时候用 / 什么时候不用

| 场景 | 推荐 | 不推荐 |
|------|------|--------|
| 卡片宽高、按钮大小 | `.size(100.rdp)` | `.size(100.dp)` |
| 装饰条/分割线 | `.height(2.dp)`（细线不缩放） | `.height(2.rdp)` 没必要 |
| 文字 | `fontSize = 14.rsp` | 系统字体设置已经会缩放 sp，rsp 保守缩放更稳 |
| Spacer 间距 | `Spacer(Modifier.height(16.dp))` 即可 | 间距通常不需要随屏缩放 |
| Tab 屏滚动列表底部 | `bottomTabContentPadding()` | 硬编码 `bottom = 80.dp` |
| 全屏覆盖动画 | 外层 `graphicsLayer.scale = sa.safeScale` | 逐个改 250.dp → 250.rdp |
| Dialog | 用 `widthIn(min, max)` + `wrapContentHeight()` | 写死 `.size(300.dp, 400.dp)` |

## 四、逐步推广建议（按优先级）

1. **高优先**：所有 Dialog（`AnniversaryDetailDialog`、`AvatarFrameDetailDialog`、`VipPaymentDialog` 等）—— 用 `heightIn(min, max = sa.heightDp.dp * 0.85f)` 限制最大高，避免小屏被裁。
2. **中优先**：游戏类大尺寸 UI（`EnhancedSpinWheelScreen` 转盘 250+dp，`RiddleGameScreen`、`DiceGameScreen`）—— 给最外层 Box `graphicsLayer.scale = sa.safeScale`。
3. **低优先**：列表 Item 卡片高度 —— 如果在小屏文字仍被裁，把 `.height(X.dp)` → `.heightIn(min = X.dp)`。
4. **可选**：将硬编码 `.size(100.dp)` 这类替换为 `100.rdp` —— 工程量大，建议有空时**仅替换"用户可见区域里看起来明显过大/过小"的元素**，不必全替。

## 五、调试小技巧

```kotlin
// 临时在屏幕角落显示当前适配信息（仅 Debug）
val sa = rememberScreenAdapter()
Text(
    "W:${sa.widthDp.toInt()}dp H:${sa.heightDp.toInt()}dp scale:${"%.2f".format(sa.safeScale)}",
    fontSize = 10.sp,
    modifier = Modifier.align(Alignment.TopEnd).padding(4.dp)
)
```

在 Android Studio Preview 里改 `@Preview(widthDp = 360)` / `widthDp = 600` 即可看不同机型效果。
